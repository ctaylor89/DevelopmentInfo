What I'd Learn First
Since you're transitioning into bookkeeping, do not try to learn every Excel feature.
Focus on this sequence:
Priority	Excel Feature
⭐⭐⭐⭐⭐	Sorting & Filtering
⭐⭐⭐⭐⭐	SUM
⭐⭐⭐⭐⭐	Tables
⭐⭐⭐⭐⭐	Cell References
⭐⭐⭐⭐⭐	SUMIF / SUMIFS
⭐⭐⭐⭐⭐	XLOOKUP
⭐⭐⭐⭐⭐	PivotTables
⭐⭐⭐⭐	IF
⭐⭐⭐⭐	Conditional Formatting
⭐⭐⭐⭐	Data Validation
⭐⭐⭐⭐	Remove Duplicates
⭐⭐⭐	Freeze Panes
⭐⭐⭐	Charts

If you become comfortable with Tables + SUMIFS + XLOOKUP + PivotTables + basic IF statements, you'll have a very solid 
Excel foundation for a typical bookkeeping position.

Insert a table:  Insert -> Table icon
Convert back to normal range: Click in table -> Table Tools -> Design Tab -> Convert to Range

Operations_In_Excel_Commonly_Used

Move columns: Click on column header -> Drag to new location
Align all columns: Select all columns -> Home Tab -> Alignment group -> Align Left / Center / Right
Size all columns: Select all columns -> Home Tab -> Cells group -> Format -> AutoFit Column Width
Sort data by a column: Select a cell in the column you want to sort by -> Data Tab -> Sort A-Z or Sort Z-A
Filter a column:
	Click anywhere inside your data.
	Go to the Data tab.
	Click Filter.		
	Excel will add a drop-down arrow to each column heading.
	Click the drop-down arrow for the column you want to filter.
	Uncheck Select All.
	Check the value(s) you want to see.
